# Skill selection for this project

Read this routing note when choosing skills. Read the selected source SKILL.md
before acting; this note is not a substitute for its instructions or live schemas.
The source survey is in docs/tech/SKILL_USAGE_GUIDE.md. The dated catalog is
.agents/skill-catalog.json; resolve current sources from the session's skill list.

## Start and scope

- Read AGENTS.md, STATE.md and the referenced brief after session start/compaction.
- Load kl-project-context first. Load kl-vietnamese-text for Vietnamese output.
- Select skills by the requested outcome, not by a shared keyword. Read only the
  supporting references needed now. Re-read a source when its hash/version changes.
- User instructions and existing authorization take precedence over skill defaults.
  Do not ask again solely because a skill says to ask. Preserve actual scope,
  paid-service authorization, unresolved canon choices and tool permission limits.

## Work routes

- Unreal inspection/edit/PIE: unreal-mcp + kl-unreal-mcp-ops. Read relevant
  registered Unreal AgentSkills through ListSkills/GetSkills; discover live schemas.
- Blueprint/HUD/rules: add kl-blueprint-architecture; content facts add kl-story-data.
- Maps/assets/generators/Git: add kl-repo-hygiene. Confirm the canonical asset from
  current STATE/defaults/references, preserve concurrent edits and make a recovery point.
- Vietnamese places/period props: kl-vietnam-world-research; keep canon, dated
  evidence, regional analogy and proposals separate. Research does not authorize scene edits.
- Complete room/asset production: build-3d-game-rooms; select the gameplay-room
  adapter and relevant references. Its gallery/layout defaults are not school canon.
- Bitmap references/textures: imagegen; built-in generation first. AI output is
  concept material, not historical evidence. Meshy spending requires explicit authorization.
- Result claims: kl-verification. Read logs/readbacks/files, inspect actual captured
  images where available, and keep physical input, audio and human acceptance distinct.
- DOCX/PDF/slides/workbook: documents/pdf/Presentations/Spreadsheets respectively.
  Read the complete applicable entrypoint and format-specific route before authoring.
- Live Excel: excel-live-control + connected-document session, not workbook-file tools.
- Codex product/configuration: openai-docs. Recurring desktop work uses native
  automation tools; do not copy a legacy shell wake loop into this app.
- GitHub work: existing Git/GitHub tools; new-repo/share/origin target a different host.
- Client-side skill authoring: built-in system skill-creator. In-editor AgentSkill
  authoring: unreal-skill. These are different registries and lifecycles.

## Verify the real operation

Run dependent Unreal calls serially. Tool availability is not editor connectivity.
Null/true alone does not prove compilation, saving or deletion. After deletion,
check the registry AND disk; preserve verified backup bytes before exact-path cleanup.
Do not resume Computer Use stopped by the user or infer a missing connector's state.
